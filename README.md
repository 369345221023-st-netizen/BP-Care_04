## 1. หน้าที่รับผิดชอบ

รับผิดชอบการทดสอบฟังก์ชันต่าง ๆ ของเว็บไซต์ BP Care เพื่อตรวจสอบความถูกต้องของการทำงาน ความสะดวกในการใช้งาน และความเข้ากันได้กับอุปกรณ์ต่าง ๆ รวมถึงรวบรวมข้อผิดพลาดและเสนอแนวทางแก้ไขให้ผู้พัฒนาระบบ

## 3. ข้อผิดพลาดที่พบ

### 3.1 ปัญหาการเชื่อมต่อ Edge Function

ระหว่างการทดสอบระบบจัดการสมาชิก พบว่าการเรียกใช้งาน Edge Function `bp-admin` ได้รับ HTTP 403 เนื่องจากการตรวจสอบ Origin ไม่ผ่าน หลังจากตรวจสอบพบว่าลิงก์ Netlify ที่ใช้งานจริงแตกต่างจากลิงก์ที่กำหนดไว้ในรายการเว็บไซต์ที่อนุญาต

**แนวทางแก้ไข:** ปรับรายการ Allowed Origins ให้ตรงกับลิงก์ Netlify ปัจจุบัน และ Deploy Edge Function ใหม่

**สถานะ:** รอยืนยันผลการทดสอบหลังแก้ไข

### 3.2 ปัญหาระบบเข้าสู่ระบบ

พบว่าการเข้าสู่ระบบด้วย Username `admin` ได้รับ HTTP 401 Unauthorized และหน้าเว็บไซต์แสดงข้อความว่าชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง

จากการตรวจสอบพบว่ามี Username `admin` อยู่ในตาราง `profiles` และมีบัญชีที่เชื่อมโยงกันใน Supabase Authentication แต่ยังไม่สามารถยืนยันได้ว่ารหัสผ่านตรงกันหรือไม่

**แนวทางแก้ไข:** ตรวจสอบข้อมูลบัญชีใน Supabase Auth และกระบวนการยืนยันรหัสผ่านใน Edge Function `bp-username-auth`

**สถานะ:** รอยืนยันผลการแก้ไข

## 4. ข้อเสนอแนะเพื่อปรับปรุงระบบ

1. ควรเพิ่มข้อความแจ้งข้อผิดพลาดที่เข้าใจง่าย เพื่อให้ผู้ใช้งานทราบว่าต้องดำเนินการอย่างไร
2. ควรตรวจสอบการทำงานของระบบเข้าสู่ระบบและสมัครสมาชิกให้มีความเสถียร
3. ควรปรับขนาดปุ่มและตัวอักษรให้เหมาะสมกับผู้สูงอายุ
4. ควรมีระบบตรวจสอบข้อมูลก่อนบันทึก เพื่อลดความผิดพลาดในการกรอกข้อมูลสุขภาพ
5. ควรพัฒนาระบบกู้คืนบัญชีอย่างปลอดภัย และตรวจสอบสิทธิ์การเข้าถึงข้อมูลสุขภาพก่อนใช้งานจริง

## 6. สรุปผลการทดสอบ

จากข้อมูลการตรวจสอบที่มีอยู่ เว็บไซต์ BP Care สามารถเปิดใช้งานผ่าน Netlify และแสดงหน้าเข้าสู่ระบบได้ แต่ยังพบข้อผิดพลาดในกระบวนการยืนยันตัวตนและการเชื่อมต่อบางส่วนของ Supabase Edge Functions

สำหรับฟังก์ชันการบันทึกข้อมูลสุขภาพ การแสดงประวัติ และการใช้งานผ่านโทรศัพท์มือถือ จำเป็นต้องให้ผู้ทดสอบดำเนินการและบันทึกผลเพิ่มเติม เพื่อประเมินความพร้อมของระบบก่อนส่งมอบ

**หมายเหตุ:** รายงานนี้เป็นร่างอ้างอิงจากข้อมูลการพัฒนาและข้อผิดพลาดที่เคยตรวจสอบ ผู้ทดสอบต้องปรับผลทดสอบและแนบหลักฐานจากการใช้งานจริงก่อนนำไปส่งเป็นผลงานของตนเอง
