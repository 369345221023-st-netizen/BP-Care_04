ผู้ใช้งานบางส่วนมีความยากลำบากในการจดบันทึกและติดตามข้อมูลสุขภาพของตนเอง โดยเฉพาะผู้สูงอายุที่ต้องการระบบใช้งานง่าย BP Care จึงถูกพัฒนาขึ้นเพื่อช่วยจัดเก็บและติดตามข้อมูลสุขภาพผ่านเว็บไซต์

กลุ่มเป้าหมาย ได้แก่ บุคคลทั่วไป ผู้ที่ต้องการติดตามสุขภาพ และผู้สูงอายุ

## ฟีเจอร์หลักและขั้นตอนทดสอบ

| ฟีเจอร์ | ขั้นตอนการทดสอบ | ผลที่คาดหวัง |
|---|---|---|
| สมัครสมาชิก | เปิดหน้าสมัครสมาชิกและกรอกข้อมูล | สร้างบัญชีใหม่ได้ |
| เข้าสู่ระบบ | กรอก Username และ Password | เข้าสู่ระบบสำเร็จ |
| บันทึกข้อมูลสุขภาพ | เข้าหน้าบันทึกและกรอกข้อมูล | บันทึกลงฐานข้อมูลได้ |
| ดูประวัติสุขภาพ | เปิดหน้าประวัติ | แสดงข้อมูลที่เคยบันทึก |
| จัดการสมาชิก | เข้าสู่ระบบด้วยบัญชีผู้ดูแลและเพิ่มสมาชิก | สร้างสมาชิกและกำหนดสิทธิ์ได้ |
| ออกจากระบบ | กดปุ่มออกจากระบบ | กลับไปหน้าเข้าสู่ระบบ |

*หมายเหตุ: ตรวจสอบให้แน่ใจว่าแต่ละฟีเจอร์ทำงานได้จริงก่อนส่งงาน*

## เทคโนโลยีที่ใช้

- Frontend: Vite และ JavaScript Framework ที่ใช้ในโปรเจกต์
- Database: Supabase (PostgreSQL)
- Authentication: Supabase Auth
- Backend: Supabase Edge Functions
- Hosting: Netlify
- Editor: Visual Studio Code

## วิธีติดตั้งและรัน

1. ติดตั้ง Node.js รุ่น LTS
2. ดาวน์โหลดโปรเจกต์และเปิดใน VS Code
3. คัดลอกไฟล์ `.env.example` เป็น `.env.local`
4. กำหนดค่าตัวแปร `VITE_SUPABASE_URL` และ `VITE_SUPABASE_KEY` ให้ตรงกับโปรเจกต์
5. เปิด Terminal แล้วรัน:

   `npm install`

6. เตรียมฐานข้อมูลตามไฟล์ในโฟลเดอร์ `database/` และตั้งค่า Supabase Edge Functions
7. เริ่มระบบด้วยคำสั่ง:

   `npm run dev`

8. เปิดเว็บไซต์ตาม URL ที่ Terminal แสดง เช่น `http://localhost:5173`

## โครงสร้างโฟลเดอร์

- `src/` — โค้ดหลักของเว็บไซต์
- `public/` — ไฟล์สาธารณะของเว็บไซต์
- `database/` — โครงสร้างฐานข้อมูลและข้อมูลตัวอย่าง
- `supabase/functions/` — โค้ด Edge Functions
- `docs/` — ภาพหน้าจอและเอกสารประกอบ
- `.env.example` — ตัวอย่างการตั้งค่าตัวแปรสภาพแวดล้อม
- `package.json` — รายการ Dependencies และคำสั่งของโปรเจกต์
